Key Concepts

Term Definition
Three-Way Handshake SYN -> SYN-ACK -> ACK, the way a TCP connection is started
Connection-Oriented A protocol that requires explicit setup before data can be transferred
Port A "hole" by which incoming TCP connections can be handled by an application
HTTP The protocol used to transfer data and information over the World Wide Web
TCP The protocol used to ensure ordered and reliable transmission of data
